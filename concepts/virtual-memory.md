# Virtual Memory

*Stub — taught in Weeks 9–10*

An abstraction that gives each process its own address space, backed by physical RAM and disk. The OS + hardware (MMU) translate virtual addresses to physical via page tables. The TLB caches recent translations.

**Related:** [[Caching]], [[Abstraction]]
