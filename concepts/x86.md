# x86

*Stub — taught in Weeks 10–14*

The ISA used by virtually all modern desktop and server CPUs. Variable-length instructions, many addressing modes, CISC heritage. CS2214 covers the basics: registers, arithmetic, stack discipline, calling conventions, encoding.
