# Binary Numbers

The base-2 number system used by digital hardware. Each bit is a power of 2. An N-bit number represents values 0 to 2ᴺ−1 (unsigned).

**Conversion:** binary → decimal by summing powers of 2. Decimal → binary by repeated division by 2.

**Why binary:** transistors have two stable states (on/off). Base-2 maps directly to physical hardware in a way base-10 cannot.
