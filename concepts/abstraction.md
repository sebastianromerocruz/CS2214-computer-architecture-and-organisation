# Abstraction

The principle that each layer of a system hides its complexity behind a clean interface, allowing the layer above to ignore implementation details. The entire computer stack — from electrons to Python — is held together by abstraction.

**The CS2214 stack:** Physics → Devices → Digital Circuits → Logic → Microarchitecture → Architecture → Operating Systems → Application Software
