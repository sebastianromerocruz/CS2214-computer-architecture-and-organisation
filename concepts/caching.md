# Caching

*Stub — taught in Weeks 8–9*

A small, fast memory that holds recently-used data to avoid slow trips to main memory. Key parameters: size, block size, associativity (direct-mapped, set-associative, fully associative). Replacement policy (LRU, random). Hit/miss rate analysis.

**NES connection:** Mapper chips perform address translation that is structurally similar to cache tag matching — mapping a CPU address into a specific bank.
