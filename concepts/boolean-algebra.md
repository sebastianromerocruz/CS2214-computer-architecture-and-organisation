# Boolean Algebra

The algebraic system for reasoning about binary values and [[logic gates]]. A Boolean expression is a formal shorthand for a circuit: `Y = AB + C̄` means exactly what the wire diagram means.

**Key rules:** commutativity, associativity, distributivity, De Morgan's laws (critical for simplification).
**Operator precedence:** NOT binds tightest, then AND, then OR — same as multiplication before addition.
