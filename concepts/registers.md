# Registers

*Stub — taught in Week 3*

N [[Flip-Flops]] sharing a clock line, storing N bits simultaneously. The register file in a processor holds the programmer-visible registers (e.g., Rg0–Rg3 in [[E15 Processor]], A/X/Y in the 6502).

**Related:** [[Flip-Flops]], [[Sequential Logic]], [[E15 Processor]], [[E20 Processor]]
