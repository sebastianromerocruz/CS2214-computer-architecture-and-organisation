# Sequential Logic

*Stub — taught in Week 3*

Circuits whose output depends on both current inputs and stored state. Requires a clock signal. Contrasts with [[circuit-analysis|combinational logic]] (output depends only on current inputs).

**Key elements:** [[Flip-Flops]], [[Registers]]
**Related:** [[Flip-Flops]], [[Registers]], [[Verilog]], [[E15 Processor]]
