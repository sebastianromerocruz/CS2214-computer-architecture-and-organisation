# Logic Gates

Circuit elements built from [[transistors]] that take binary inputs and produce a binary output according to a fixed Boolean rule. The three primitives — AND, OR, NOT — are sufficient to implement any Boolean function. NAND alone is universal.

**Gates covered in CS2214:** NOT, AND, OR, XOR, NAND, NOR

**NES connection:** The 6502's status register uses bitwise AND/OR masking to test and set flags — the same gate-level operations, just at the byte scale.
