# Truth Tables

An exhaustive enumeration of a Boolean function's output for every possible combination of inputs. A function of N inputs has 2ᴺ rows. Truth tables, [[Boolean Algebra|Boolean expressions]], and circuit diagrams are three equivalent representations of the same thing.

**Exam skill:** Given any two, derive the third.
