# Hexadecimal

Base-16 notation (digits 0–9, A–F). One hex digit = exactly 4 bits, so hex is a compact human-readable shorthand for binary. Machine language listings, memory addresses, and CPU registers are almost always shown in hex.

**NES connection:** Every NES memory address is a 16-bit hex value — `$FFFC`, `$0100`, `$8000`. The 6502 programmer lives in hex.
